# THEORY, VIVA Q&A, ALGORITHM AND COMPLEXITY - ASSIGNMENT 3 (Bank Customer Churn, Neural Network Classifier)
#
# 1. WHAT THIS PRACTICAL DOES
# Goal: predict whether a bank customer will leave (Exited = 1) or stay (Exited = 0) using a neural network.
# Dataset: Churn_Modelling.csv, 10,000 customers, about 20% of whom left (class imbalance).
# Steps in the code:
#  a) Load the data, check nulls, drop identifier columns RowNumber, CustomerId, Surname.
#  b) Visualise Tenure and Age against churn with histograms.
#  c) Convert the categorical columns Geography and Gender into dummy (one-hot) variables with drop_first = True. This leaves 11 input features.
#  d) Split 70% train / 30% test.
#  e) Normalise with StandardScaler (fit on the training data, transform the test data).
#  f) Build and train the network, predict on the test set, threshold at 0.5.
#  g) Evaluate with accuracy, confusion matrix and classification report.
#
# 2. KEY CONCEPTS
# - Artificial Neural Network (ANN) / Multilayer Perceptron (MLP): layers of neurons. Each neuron computes a weighted sum of its inputs plus a bias and passes it through an activation function.
# - Layers: input layer (11 features), hidden layers (learn patterns), output layer (1 neuron giving the churn probability).
# - ReLU activation: f(x) = max(0, x). Used in hidden layers because it is simple and avoids the vanishing gradient problem.
# - Sigmoid activation: f(x) = 1 / (1 + e^-x). Squashes the output into 0..1 so it can be read as a probability. Used in the output layer for binary classification.
# - Loss function: binary cross-entropy = -[ y*log(p) + (1-y)*log(1-p) ]. It measures how wrong the predicted probability is.
# - Optimiser Adam: gradient descent with adaptive learning rates (combines momentum and RMSProp).
# - Backpropagation: the chain rule is used to compute the gradient of the loss with respect to every weight, then the weights are updated.
# - Epoch: one full pass over the training data. Batch size: number of samples per weight update.
# - One-hot encoding: turns a category into 0/1 columns. drop_first removes one redundant column (avoids the dummy variable trap).
# - Why scale features: neural networks train faster and more stably when inputs are on similar scales.
# - Confusion matrix and metrics: precision, recall, F1, accuracy (see Assignment 2).
#
# 3. ALGORITHM (training a neural network)
#  1. Initialise all weights (small random values) and biases.
#  2. Forward propagation: for each layer compute a = activation(W * input + b), until the output probability p.
#  3. Compute the loss (binary cross-entropy) between p and the true label.
#  4. Backpropagation: compute the gradient of the loss for every weight, layer by layer from output to input.
#  5. Update the weights with Adam.
#  6. Repeat steps 2 to 5 for every batch, and for every epoch (or until early stopping).
#  7. Prediction: forward pass; if p > 0.5 predict "Exited", otherwise "Stayed".
#
# 4. TIME AND SPACE COMPLEXITY  (W = total number of weights, n = training samples, E = epochs)
# - Forward pass: O(W) per sample. Backpropagation: O(W) per sample, the same order as the forward pass.
# - Training: O(E * n * W) time. Space: O(W) for the parameters plus the activations of one batch.
# - Prediction: O(W) per sample, so O(m * W) for m test samples.
# - Preprocessing (scaling, one-hot): O(n * d).
# - For a fully connected network the weights are W = sum of (neurons in layer i * neurons in layer i+1) + biases.
#
# 5. LIKELY VIVA QUESTIONS AND ANSWERS
# Q1. What is a neural network?
# A. A model made of layers of connected neurons. Each neuron takes a weighted sum of its inputs, adds a bias and applies an activation function. The weights are learned from data.
# Q2. Why drop RowNumber, CustomerId and Surname?
# A. They only identify a customer and carry no predictive information. Keeping them adds noise.
# Q3. Why one-hot encode Geography and Gender? Why drop_first?
# A. Neural networks need numbers, and plain codes like 0/1/2 would imply a false order. One-hot columns avoid that; dropping one column avoids redundancy (the dummy variable trap).
# Q4. Why scale the features?
# A. Features like Balance (up to 250,000) and Age (about 40) have very different ranges. Without scaling, large features dominate and training is slow or unstable. Fit the scaler on training data only, so no test information leaks.
# Q5. Why ReLU in the hidden layers and sigmoid in the output?
# A. ReLU is cheap and trains well. Sigmoid outputs a value between 0 and 1, which is the churn probability for a binary problem.
# Q6. Why binary cross-entropy?
# A. The task has two classes and the output is a probability. Cross-entropy punishes confident wrong predictions heavily and gives good gradients with a sigmoid output.
# Q7. What is Adam?
# A. An optimiser that adapts the learning rate for each weight using running averages of the gradient and the squared gradient. It usually converges faster than plain gradient descent.
# Q8. What are epochs and batch size?
# A. An epoch is one pass over all training data. The batch size is how many samples are used before each weight update.
# Q9. What is backpropagation?
# A. It uses the chain rule to compute how much each weight contributed to the error, from the output layer back to the input layer, so the weights can be updated.
# Q10. How many parameters are there in the original Keras model (11 -> 6 -> 6 -> 1)?
# A. Layer 1: 11*6 + 6 = 72. Layer 2: 6*6 + 6 = 42. Output: 6*1 + 1 = 7. Total 121 (this matches model.summary()).
# Q11. Why is accuracy misleading here?
# A. About 80% of customers stay, so predicting "stay" for everybody already gives about 80% accuracy. Look at recall and precision for the Exited class too.
# Q12. What is class imbalance and how do you handle it?
# A. One class has far fewer samples. Remedies: oversampling the minority class, undersampling the majority class, SMOTE, class weights, or choosing a different decision threshold.
# Q13. What is overfitting and how do you reduce it?
# A. The network memorises the training data and does poorly on new data. Use fewer neurons, L2 regularisation, dropout, early stopping, and more data.
# Q14. Why threshold at 0.5? Can it change?
# A. 0.5 is the default for balanced classes. For churn you can lower it (for example 0.3) to catch more churners (higher recall) at the cost of more false alarms.
# Q15. Why did the number of hidden neurons (6) get chosen?
# A. It is a small starting design; there is no fixed rule. Tune the number of layers and neurons with validation accuracy or cross-validation.
# Q16. What is the difference between Keras, TensorFlow and scikit-learn's MLPClassifier?
# A. TensorFlow is the low-level deep learning library. Keras is a high-level API on top of it. MLPClassifier is a simpler, CPU-only MLP inside scikit-learn, convenient for small tabular data.
# Q17. What does the classification report show?
# A. Precision, recall, F1-score and support (number of samples) for each class, plus accuracy and the macro and weighted averages.
