# THEORY, VIVA Q&A, ALGORITHM AND COMPLEXITY - ASSIGNMENT 5 (K-Means Clustering on Sales Data, Elbow Method)
#
# 1. WHAT THIS PRACTICAL DOES
# Goal: group the sales records into clusters (customer / order segments) with K-Means and find the best number of clusters with the elbow method. This is UNSUPERVISED learning, so there is no target label.
# Dataset: sales_data_sample.csv (orders with quantity, price, sales, product line, deal size, country, etc.). It is read with encoding = "Latin-1" because it contains non-UTF-8 characters.
# Steps in the code:
#  a) Load and inspect the data (head, shape, describe, info, null counts, dtypes).
#  b) Drop columns that are free text, identifiers or mostly missing: ADDRESSLINE1/2, STATUS, POSTALCODE, CITY, TERRITORY, PHONE, STATE, CONTACT names, CUSTOMERNAME, ORDERNUMBER.
#  c) One-hot encode PRODUCTLINE and DEALSIZE, then drop the originals. Drop COUNTRY (too many values) and ORDERDATE (MONTH_ID and YEAR_ID already hold the information). Convert PRODUCTCODE to numeric category codes.
#  d) Elbow method: run KMeans for k = 1 to 9 and store the inertia (distortion) of each. Plot k against inertia.
#  e) The elbow is at k = 3, so fit KMeans with 3 clusters (random_state = 2) and predict the cluster of every row. Count the rows per cluster.
#  f) Visualise: reduce all features to 2 components with PCA, then scatter plot the points, the 3 centroids and the clusters in different colours.
#
# 2. KEY CONCEPTS
# - Clustering: grouping similar items without labels.
# - K-Means: partitions the data into k clusters. Each cluster has a centroid (mean of its points). Every point belongs to the nearest centroid.
# - Inertia / distortion / WCSS (Within-Cluster Sum of Squares): sum of squared distances from every point to its own centroid. K-Means minimises it.
# - Elbow method: plot inertia against k. Inertia always falls as k grows, but after the "elbow" the improvement becomes small. The elbow point is a good k.
# - k-means++ initialisation (the default in scikit-learn): picks well-spread starting centroids, which gives better and faster results than purely random starts.
# - PCA (Principal Component Analysis): a linear dimensionality reduction that projects the data onto the directions of maximum variance. Used here only to draw high-dimensional data in 2D.
# - Hierarchical (agglomerative) clustering: the assignment title also allows this. It starts with each point as its own cluster and repeatedly merges the two closest clusters; the result is drawn as a dendrogram.
# - One-hot / category codes: convert text columns into numbers because K-Means needs numeric input.
#
# 3. ALGORITHM (K-Means, Lloyd's algorithm)
#  1. Choose k (from the elbow method).
#  2. Initialise k centroids (k-means++).
#  3. Assignment step: assign every point to its nearest centroid (Euclidean distance).
#  4. Update step: recompute each centroid as the mean of the points assigned to it.
#  5. Repeat steps 3 and 4 until the assignments stop changing (or the maximum iterations are reached).
#  6. Output: the cluster label for each point and the final centroids.
# Elbow method
#  1. For k = 1..9 run K-Means and record the inertia.
#  2. Plot k against inertia and pick the k where the curve bends.
# Hierarchical clustering (agglomerative), if asked
#  1. Start with n clusters (one per point).
#  2. Compute the distance matrix and merge the two closest clusters (single, complete, average or Ward linkage).
#  3. Update the distances and repeat until one cluster is left. Cut the dendrogram at the desired height to get the clusters.
#
# 4. TIME AND SPACE COMPLEXITY  (n = points, d = features, k = clusters, I = iterations)
# - K-Means: O(n * k * d * I) time. Space: O(n*d + k*d).
# - Elbow loop for k = 1..9: it runs K-Means nine times, so the total is about O(n * d * I * (1+2+...+9)) = O(45 * n * d * I).
# - Finding the global optimum is NP-hard; K-Means converges to a local minimum, which is why several initialisations (n_init) or a fixed random_state are used.
# - PCA: O(n * d^2 + d^3) with the covariance / SVD method. Space O(n*d).
# - Hierarchical clustering: O(n^3) time with the naive method, O(n^2 log n) with a priority queue. Space O(n^2) for the distance matrix. It is therefore not suitable for very large data, whereas K-Means scales almost linearly in n.
# - get_dummies and dropping columns: O(n*d).
#
# 5. LIKELY VIVA QUESTIONS AND ANSWERS
# Q1. What is clustering? How is it different from classification?
# A. Clustering is unsupervised: it finds groups in unlabeled data. Classification is supervised: it learns from labeled data to predict a known label.
# Q2. How does K-Means work?
# A. It repeats two steps: assign each point to the nearest centroid, then move each centroid to the mean of its points, until nothing changes.
# Q3. What is the elbow method?
# A. Plot the inertia for different values of k and choose the k where the drop in inertia slows sharply (the "elbow"). Here that point is k = 3.
# Q4. What is inertia?
# A. The sum of squared distances between every point and the centroid of its cluster. Lower means tighter clusters.
# Q5. Why does inertia always decrease as k increases?
# A. More centroids mean each point is closer to some centroid. With k = n the inertia is 0, so inertia alone cannot pick k and we look for the elbow.
# Q6. How else can you choose k?
# A. Silhouette score, the gap statistic, the Davies-Bouldin index, or domain knowledge.
# Q7. Why drop columns like ADDRESSLINE2, PHONE, STATE and so on?
# A. They are text, identifiers or contain many missing values, so they do not help distance-based clustering.
# Q8. Why one-hot encode PRODUCTLINE and DEALSIZE?
# A. K-Means needs numbers. One-hot columns turn categories into 0/1 without implying an order.
# Q9. Why use PCA before plotting?
# A. The data has many dimensions and cannot be drawn directly. PCA compresses it to 2 components that keep as much variance as possible, so the clusters can be visualised.
# Q10. Does K-Means need scaling?
# A. Yes, in general. K-Means uses Euclidean distance, so columns with big numbers (SALES, MSRP) dominate columns with small numbers. In this notebook the features were not scaled, so the clusters are driven mostly by the large-valued columns. Applying StandardScaler before KMeans is a good improvement to mention.
# Q11. What are the limitations of K-Means?
# A. You must choose k in advance, it is sensitive to the starting centroids and to outliers, it assumes roughly spherical clusters of similar size, and it needs numeric data.
# Q12. What is k-means++?
# A. A smart initialisation that picks the first centroid at random and each next centroid with probability proportional to its squared distance from the nearest chosen centroid. It spreads the starting centroids out.
# Q13. What is hierarchical clustering and how does it differ from K-Means?
# A. It builds a tree (dendrogram) by repeatedly merging the closest clusters; you do not need to give k in advance (you cut the tree). It is slower, O(n^2) or worse, but gives a full hierarchy. K-Means is faster and needs k up front.
# Q14. What is a centroid?
# A. The mean position of all points in a cluster.
# Q15. How do you decide whether the clustering is good?
# A. Look at inertia, the silhouette score (between -1 and 1; higher is better), the cluster sizes, and whether the clusters make business sense (for example high-value large orders vs small orders).
# Q16. What does random_state do?
# A. It fixes the random initialisation, so you get the same clusters on every run.
